THE FIXED POINT the value a function sends to itself — x = f(x), the still point of a map

A fixed point of a map is a value it leaves unmoved: x = f(x). Iterate the map from almost anywhere and, if it is a contraction, you spiral in to that one still value — it is where the motion stops. The whole batch is faces of this: a root is a fixed point of Newton's map, φ is the fixed point of x→1+1/x, a least solution is the fixed point of a monotone map, an attractor is where a dynamical system comes to rest. Everything that computes by settling is finding a fixed point. Here the plainest one: iterate the Heron map x→(x+2/x)/2 and it settles on the value where f(x)=x — √2.

Not a keeper (a converged value is one every correct iteration reaches — the B42 tell: convergence to a unique value is witnessed, and a unique settled value is a normal form, which is the confluence axis).
