THE HORNER SCHEME nest the polynomial — ((2x+3)x+4)x+5, n mults not n²

Evaluating 2x³+3x²+4x+5 the obvious way recomputes powers of x over and over — roughly n²/2 multiplications. Horner’s scheme factors the polynomial into a nest: ((2x+3)x+4)x+5. Now each coefficient is folded in with a single multiply-add, so a degree-n polynomial costs exactly n multiplications and n additions — provably optimal for a general polynomial. Same value, every time; the nesting only removes wasted work. It is the multiply-accumulate at the heart of every DSP chip.

HISTORY & CREDIT Ruffini 1804 · Horner 1819 · Qin 1247

  
“A polynomial is a sum of powers.” — to compute it, it is a nest of multiply-adds; the sum-of-powers form is the wasteful one. cited

  
the nest · a₃x³+a₂x²+a₁x+a₀ = ((a₃x+a₂)x+a₁)x+a₀ — factor out x repeatedly.
optimal · a general degree-n polynomial needs at least n mults (Ostrowski / Pan) — Horner meets the bound.
c.1804 / 1819 / 1247 · Paolo Ruffini published the same algorithm in Europe ~1804 (hence the “Ruffini–Horner” method); William Horner gave it its name (1819); Qin Jiushao used it in China ~1247.

RECOMMEND FOR I-13 nested vs naive, on the compiler

  
On the canonical compiler, at x=2 the nested Horner form and the naive power form return the identical 41:

  
$ i13 run tk_horner.i13   # ((2x+3)x+4)x+5  vs  2x^3+3x^2+4x+5
RUN OK · 50 step(s) · peak stack 3 · call depth 1
x = 2
ph = 41   -- Horner (3 mults)
pn = 41   -- naive (6 mults)
same = 1  -- bit-identical value

  
Recommend as a clean NULL and a gate exemplar. Horner is the textbook case of the resource axis (B40): the output is bit-identical to the naive evaluation — i13 prints 41 both ways — and the only thing that changes is the multiplication count (n vs ~n²/2). By the rule that a property is a keeper only if a correct-but-different mechanism can change the value, Horner changes nothing but cost. It is the sharpest possible illustration of why speed is not an axis: a costlier twin gives the same bits. NULL, and useful precisely for that.
