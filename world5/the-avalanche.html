THE AVALANCHE EFFECT flip one input bit, flip half the output — the mark of good mixing

A good hash or cipher has the avalanche effect: change a single input bit and about half of the output bits flip, unpredictably. It means every output bit depends on every input bit, so no partial correlation survives for an attacker to exploit — the output looks random even for inputs that barely differ. The strict form (each output bit flips with probability exactly ½ for each input-bit flip) is the design target of every round function in AES, SHA, and friends. It is how diffusion is measured: one pebble in, half the mountain moves.

THE TECHNIQUE 1 input-bit flip ⇒ ~50% of output bits change (diffusion)

The demo hashes a value with a 16-bit mixing function, flips one input bit, and counts how many output bits changed — about half: live demo
