THE A* SEARCH Dijkstra with a hunch — f = g + h, and it never overshoots

A* is Dijkstra given a sense of direction. It prioritizes nodes not by distance-so-far alone but by f = g + h — the cost g already spent plus a heuristic estimate h of the cost remaining to the goal. If the heuristic is admissible (it never overestimates the true remaining cost), A* is guaranteed to find the optimal path while exploring far fewer nodes than Dijkstra — the estimate steers it toward the goal. Set h = 0 and A* becomes exactly Dijkstra; a good heuristic (like straight-line distance) makes it the pathfinder of games, robots, and routing. Here g=1, an admissible h=3, so f=4 — and 4 does not exceed the true cost 4.
