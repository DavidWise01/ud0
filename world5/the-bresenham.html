BRESENHAM’S LINE draw a straight line with only add and compare — no float, no divide

To draw a line on a grid you must choose, at each column, which pixel is closest — and Bresenham’s 1962 algorithm does it with only integer add and compare, no floating point and no division. It carries an error term that accumulates the slope; when it crosses a threshold, the line steps up a row and the error resets. Every plotter, every early display, every line you have ever seen on a pixel grid traces to it. From (0,0) to (6,4) the accumulated y reaches exactly 4 at the far end — a perfect integer line.

THE TECHNIQUE err += 2·dy; if err > dx: y++, err −= 2·dx — integers only

The demo runs Bresenham from (0,0) to (6,4) with integer arithmetic only — the y reaches 4 at the endpoint: live demo
